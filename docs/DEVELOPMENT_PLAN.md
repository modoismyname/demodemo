# 풋살 팀 밸런서 — 개발계획서 (v1.1)

> 상태: **계획 확정**. 다음 단계는 화면 디자인 컨펌입니다. 각 단계는 사용자 컨펌 후 다음 단계로 진행합니다.

## 1. 개요

풋살 경기 전에 참석 인원을 기준으로 균형 잡힌 팀(또는 수준별 팀)을 자동으로 편성합니다. 편성 결과는 날짜별로 확정해 JSON으로 저장하고 다시 불러올 수 있으며, PDF로도 출력합니다.

## 2. 기술 스택 (제안)

| 항목 | 선택 | 비고 |
|---|---|---|
| 언어/프레임워크 | **Flutter (Dart)** | 요구사항 14 |
| 타깃 플랫폼 | **Flutter Web (확정)** | 설치 없이 PC와 모바일 브라우저에서 사용합니다. Android 앱은 이번 범위에서 제외합니다. |
| 상태관리 | `provider` 또는 `riverpod` | 규모가 작아 가벼운 방식을 씁니다. |
| 로컬 저장 | `shared_preferences` (웹에서는 브라우저 localStorage) | 선수 명단과 능력치를 자동으로 보관합니다. |
| JSON 저장/불러오기 | `file_picker` + 웹 다운로드 | 요구사항 10, 11 |
| PDF | `pdf` + `printing` | **한글 폰트(Noto Sans KR)를 내장**해야 글자가 깨지지 않습니다. |
| 공유 이미지 | `RepaintBoundary` → PNG, 웹 Clipboard API | 팀별 명단 이미지를 클립보드에 복사합니다. 지원하지 않는 브라우저에서는 PNG로 내려받습니다. |
| 날짜 선택 | Flutter 기본 `showDatePicker` (한국어 로케일) | 요구사항 9 |

### 백엔드/DB 판단 (요구사항 15)
- **v1은 백엔드와 DB를 만들지 않습니다 (확정).** 한 기기에서만 사용합니다. 선수 명단은 브라우저 로컬 저장소에 두고, 확정한 편성표는 JSON 파일로 저장합니다.
- **백엔드가 필요해지는 경우(제안):**
  1. 여러 사람이나 여러 기기에서 같은 선수 명단을 공유하고 싶을 때 → Firebase(Firestore) 같은 BaaS를 쓰면 서버를 직접 만들지 않아도 됩니다.
  2. AI 모델(요구사항 8)을 사용할 때 → API 키를 브라우저에 노출하면 안 되므로 작은 서버리스 프록시가 1개 필요합니다(예: Cloudflare Workers, Firebase Functions).

## 3. 데이터 모델

```jsonc
// 선수
{ "id": "uuid", "name": "홍길동",
  "stats": { "stamina": 2, "speed": 3, "skill": 1, "teamwork": 2, "condition": 3 } }  // 각 1~3

// 확정 편성표 (JSON 저장 파일)
{
  "schemaVersion": 1,
  "matchDate": "2026-10-11",
  "mode": "balanced",            // balanced(평준화) | tiered(전문화)
  "confirmedAt": "2026-10-07T21:00:00+09:00",
  "teams": [
    { "name": "A팀", "players": [ /* 선수 객체 (능력치 스냅샷 포함) */ ],
      "totals": { "stamina": 10, "speed": 11, "skill": 9, "teamwork": 10, "condition": 12, "sum": 52 } }
  ],
  "bench": []                    // 교체대기 명단 (팀에 들어가지 못한 선수)
}
```
- 편성표에는 **능력치 스냅샷**을 저장합니다. 나중에 선수 능력치를 바꿔도 과거 편성표는 그대로 유지됩니다.
- 파일 이름 규칙: `futsal_teams_2026-10-11.json`

## 4. 팀 편성 로직

### 4-1. 팀 수와 팀 인원 결정 (요구사항 4) — 확정 규칙 (v1.1 변경)
사용자가 **팀 수를 2팀 또는 3팀 중에서 선택**합니다 (기본값 2팀, 최대 3팀). 팀 수를 k, 참석 인원을 N명이라고 하면:
1. **N < 5k → "경기 불가"** 안내만 표시합니다. 2팀은 최소 10명, 3팀은 최소 15명이 필요합니다.
2. 팀에 들어갈 인원 = min(N, 7k)명이고, 이 인원을 k팀에 **최대 1명 차이로 고르게** 나눕니다.
3. 7k명을 넘는 인원(N − 7k)은 **교체대기**에 넣습니다.
4. 팀 이름은 순서대로 **A팀, B팀, C팀**으로 붙입니다.

| 참석 | 2팀 선택 | 3팀 선택 |
|---|---|---|
| 1~9 | 경기 불가 | 경기 불가 |
| 10 | A5 + B5 | 경기 불가 |
| 11 | A6 + B5 | 경기 불가 |
| 13 | A7 + B6 | 경기 불가 |
| 14 | A7 + B7 | 경기 불가 |
| 15 | A7 + B7 + 대기1 | A5 + B5 + C5 |
| 16 | A7 + B7 + 대기2 | A6 + B5 + C5 |
| 18 | A7 + B7 + 대기4 | A6 + B6 + C6 |
| 20 | A7 + B7 + 대기6 | A7 + B7 + C6 |
| 21 | A7 + B7 + 대기7 | A7 + B7 + C7 |
| 23 | A7 + B7 + 대기9 | A7 + B7 + C7 + 대기2 |

### 4-1-2. 빈 슬롯 (v1.1 추가)
- 팀을 구성하면 **각 팀 카드에 빈 슬롯 2개**를 함께 표시합니다. 팀 정원은 배정 인원 + 2이고, 선수를 다른 팀으로 옮기면 원래 팀에는 빈 슬롯이 하나 늘어납니다.
- 선수를 끌어서 놓는 규칙:
  - 빈 슬롯에 놓으면 그 팀으로 이동합니다.
  - 다른 선수 위에 놓으면 두 선수를 맞바꿉니다.
  - 교체대기에는 인원 제한 없이 놓을 수 있습니다.
- 빈 슬롯이 없는 팀에는 맞바꾸기만 할 수 있습니다.
- 팀 인원이 5~7명을 벗어나면 경고를 표시하고, 그 상태에서는 확정할 수 없습니다.
- 팀을 확정하면 빈 슬롯은 숨깁니다.

### 4-1-1. 교체대기 선수 선정 (확정)
- 대기 인원은 **무작위로** 뽑습니다 (확정). 같은 사람이 연속으로 뽑혀도 괜찮습니다.
- 사용자가 끌어서 놓는 방식으로 대기 선수와 팀 선수를 맞바꿀 수 있습니다.
- 대기 선수를 먼저 뽑고, 나머지 선수로 평준화나 전문화 편성을 합니다.

### 4-2. 선수 점수
- 기본 점수 = 5개 능력치의 합 (5~15점)
- 항목별 가중치는 v1에서 모두 1로 둡니다. 나중에 설정 화면으로 조정할 수 있게 확장합니다.

### 4-3. 평준화 (balanced)
1. 점수 내림차순으로 정렬한 뒤 **스네이크 드래프트**로 1차 배정합니다 (A→B→C→C→B→A…).
2. **교환 최적화**: 두 팀 사이에서 선수를 맞바꿔 아래 비용이 줄어들면 교환합니다. 더 이상 줄어들지 않을 때까지 반복합니다.
   - 비용 = 팀 총점 편차 × 큰 가중치 + 항목별(활동량/스피드/개인기/협동력/컨디션) 팀 합계 편차의 합
   - 총점만 맞추는 것이 아니라 **각 능력치 항목도 고르게** 분산합니다.
3. 동점이 많을 때는 무작위 요소를 넣어 "다시 구성" 버튼을 누를 때마다 다른 조합이 나오게 합니다.

### 4-4. 전문화 (tiered)
1. 점수 내림차순으로 정렬합니다.
2. 1팀에는 상위 선수부터 정원만큼, 2팀에는 그다음 선수들을 배정하는 식으로 차례대로 채웁니다.
3. 경계에서 점수가 같은 선수들은 항목 균형을 고려하거나 무작위로 배정합니다.

### 4-5. AI 모델 사용 (요구사항 8) — v2로 연기 (확정)
- 평준화와 전문화 모두 위 알고리즘만으로 판단할 수 있으므로 **v1에서는 AI 모델을 쓰지 않습니다.**
- v2 후보: 온라인일 때만 켜지는 "AI 검토" 기능. 알고리즘이 만든 편성안을 Claude API로 검토해 교환안을 받고, 실제로 비용을 줄이는 안만 적용합니다. 이 기능에는 API 키를 숨길 프록시 서버가 필요합니다.

## 5. 화면 구성 (초안 — 디자인은 별도 컨펌)

1. **선수 관리**: 선수 목록, 추가/수정/삭제, 능력치 5항목 설정(1~3 선택 버튼), 총점 표시
2. **경기 편성** (메인)
   - 경기 날짜 선택
   - **팀 수 선택: 2팀 / 3팀**
   - 참석 체크 목록(전체 선택/해제), 참석 인원과 예상 팀 구성(예: "18명 → A6 + B6 + C6") 표시
   - 편성 옵션: 평준화 / 전문화
   - [팀 구성] → 팀별 카드(선수, 항목별 합계, 총점)와 **교체대기 카드** 표시
   - **드래그 앤 드롭 (확정)**: 선수를 끌어서 다른 팀이나 대기 명단으로 옮깁니다. 다른 선수 위에 놓으면 두 선수를 맞바꿉니다. 옮길 때마다 팀 합계를 다시 계산하고, 팀 인원이 5~7명을 벗어나면 경고를 표시합니다.
   - [팀 확정] → 편성 잠금 + JSON 저장
   - [불러오기] → JSON을 열어 날짜와 편성을 복원하고 다시 편집
   - [출력] → 확정한 편성표를 PDF로 출력
   - **[공유] (추가 요구사항)** → 팀별 명단만 담은 이미지를 만들어 미리보기로 보여 줍니다.
     - 내용: 경기 날짜, 팀 이름(팀 색 표시), 선수 이름, 교체대기 명단. **능력치와 점수는 넣지 않습니다.**
     - [이미지 복사]를 누르면 클립보드에 복사되어 카카오톡 등에 바로 붙여 넣을 수 있습니다. [이미지 저장]으로 PNG 파일도 받을 수 있습니다.
     - 휴대폰 브라우저에서 클립보드 복사가 안 되면 기기의 공유 메뉴(Web Share)를 열거나 PNG를 내려받습니다.
     - [출력]과 마찬가지로 팀 확정 뒤에 켜집니다.
3. 하단 탭 또는 사이드 메뉴로 1번과 2번 화면을 오갑니다.
