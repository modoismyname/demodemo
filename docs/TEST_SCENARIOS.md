# 풋살 팀 밸런서 — 테스트 시나리오 (v1.0)

> 상태: **사용자 컨펌 대기**. 모든 시나리오를 컨펌하면 최종본으로 확정합니다.
>
> 표시: ✅ 개발 중 자동 테스트(단위 테스트 또는 브라우저 자동 조작)로 확인함 · 👀 사용자 확인 필요

## 준비
- PC는 Chrome 또는 Edge, 휴대폰은 Chrome(Android) 또는 Safari(iPhone)로 접속합니다.
- 처음 접속하면 선수 명단이 비어 있습니다.

## A. 선수 관리

| ID | 시나리오 | 절차 | 기대 결과 | 확인 |
|---|---|---|---|---|
| A-1 | 선수 등록 | [선수 관리] 탭 → 이름 입력 → [선수 추가] 또는 Enter | 목록에 추가되고 5개 능력치가 모두 2, 합계 10으로 표시 | ✅ |
| A-2 | 중복 이름 거부 | 이미 있는 이름을 다시 등록 | "이미 같은 이름의 선수가 있습니다" 안내, 추가되지 않음 | ✅ |
| A-3 | 빈 이름 거부 | 이름 칸을 비우고 [선수 추가] | 아무것도 추가되지 않음 | ✅ |
| A-4 | 능력치 설정 | 각 항목의 1·2·3 버튼 클릭 | 선택한 숫자가 강조되고 합계가 바로 바뀜 | ✅ |
| A-5 | 이름 수정 | 연필 아이콘 → 새 이름 → [저장] | 이름이 바뀜. 중복 이름이면 거부 | 👀 |
| A-6 | 선수 삭제 | 휴지통 아이콘 → [삭제] | 확인 창 후 목록에서 사라지고 참석 체크에서도 빠짐 | 👀 |
| A-7 | 자동 저장 | 선수와 능력치를 바꾼 뒤 브라우저 새로고침 | 명단과 능력치가 그대로 남아 있음 | ✅ |
| A-8 | 휴대폰 화면 | 휴대폰으로 [선수 관리] 열기 | 선수별 카드 형태로 표시, 1·2·3 버튼을 누를 수 있음 | ✅ |

| B-3 | 날짜별 보관 | 날짜 X에서 편성 → 날짜 Y로 변경 → 다시 X로 변경 | X의 참석 체크와 편성이 그대로 복원됨 | ✅ |
| B-4 | 참석 체크 | 선수 체크/해제 | "참석 체크 n/전체" 숫자와 상단 안내가 바로 바뀜 | ✅ |
| B-5 | 전체 선택/해제 | [전체 선택] → [전체 해제] | 모두 체크/모두 해제 | ✅ |
| B-6 | 참석 변경 시 편성 초기화 | 팀 구성 후 참석 체크를 바꿈 | 기존 팀 카드가 사라짐 (다시 구성 필요) | 👀 |

## D. 팀 구성 (평준화 / 전문화)

| ID | 시나리오 | 절차 | 기대 결과 | 확인 |
|---|---|---|---|---|
| D-1 | 평준화 | [평준화] 선택 → [팀 구성] | 팀 총점이 서로 비슷함 (인원이 같으면 대개 0~3점 차이), 항목별 합계도 고르게 분산 | ✅ |
| D-2 | 전문화 | [전문화] 선택 → [팀 구성] | A팀에 점수 높은 선수들, B팀은 그다음, C팀은 그다음 순서 | ✅ |
| D-3 | 다시 구성 | 팀 구성 후 [다시 구성] 반복 | 교체대기 선수와 동점자 배치가 바뀌며 새 편성이 나옴 | 👀 |
| D-4 | 옵션 변경 | 팀 구성 후 평준화↔전문화 변경 | 바뀐 방식으로 즉시 다시 구성됨 | 👀 |
| D-5 | 교체대기 무작위 | 교체대기가 생기는 인원으로 여러 번 구성 | 교체대기 선수가 무작위로 바뀜 (같은 사람이 연속으로 나와도 정상) | 👀 |
| D-6 | 팀 카드 표시 | 팀 구성 후 카드 확인 | 팀 이름(A/B/C, 색 구분), 인원, 총점, 선수별 점수, 항목별 합계 5개, 빈 슬롯 2개 | ✅ |

## E. 드래그로 선수 옮기기

| ID | 시나리오 | 절차 | 기대 결과 | 확인 |
|---|---|---|---|---|
| E-1 | 빈 슬롯으로 이동 | A팀 선수를 끌어 B팀 빈 슬롯에 놓기 | A팀 인원 -1(빈 슬롯 +1), B팀 인원 +1(빈 슬롯 -1), 합계 즉시 갱신 | ✅ |
| E-2 | 맞바꾸기 | 선수를 다른 팀 선수 위에 놓기 | 두 선수 위치가 바뀜 | ✅ |
| E-3 | 교체대기로 이동/교체 | 팀 선수를 교체대기 카드에 놓기, 교체대기 선수를 팀 선수 위에 놓기 | 교체대기로 이동 / 서로 맞바뀜 | ✅ |
| E-4 | 빈 슬롯 없음 | 빈 슬롯이 0개인 팀의 빈 공간에 놓기 | "빈 슬롯이 없습니다. 선수 위에 놓아 맞바꾸세요." 안내 | ✅ |
| E-5 | 인원 경고 | 이동 결과 팀 인원이 8명 또는 4명이 됨 | 팀 카드에 "팀 인원은 5~7명이어야 합니다" 경고 | ✅ |
| E-6 | 휴대폰 드래그 | 휴대폰에서 선수를 **길게 누른 뒤** 끌기 | PC와 같은 동작 | 👀 |

## F. 팀 확정과 JSON 저장/불러오기

| ID | 시나리오 | 절차 | 기대 결과 | 확인 |
|---|---|---|---|---|
| F-1 | 인원 오류 시 확정 불가 | 인원 경고가 있는 상태에서 [팀 확정] | "확정할 수 없습니다" 창에 문제 팀 이름 표시 | ✅ |

| F-4 | 수정 | [수정] 클릭 | 잠금이 풀리고 다시 편집 가능 ([출력]/[공유] 비활성) | ✅ |
| F-5 | 불러오기 | [불러오기] → 저장한 JSON 선택 | 파일의 날짜로 이동하고 확정 편성이 그대로 표시됨 | ✅ |
| F-6 | 다른 기기에서 불러오기 | 명단이 빈 브라우저에서 JSON 불러오기 | "명단에 없던 선수 n명을 추가했습니다" 안내, 선수 관리에도 추가됨 | ✅ |
| F-7 | 불러온 뒤 재편집 | 불러온 뒤 [수정] → 드래그 또는 [다시 구성] → [팀 확정] | 정상 편집과 재확정, 새 JSON 저장 | 👀 |
| F-8 | 잘못된 파일 | 다른 JSON이나 텍스트 파일 불러오기 | "파일을 읽을 수 없습니다" 안내, 기존 편성 유지 | 👀 |

### 자동 테스트 실행 결과 (개발 환경)
- 단위 테스트 26개 통과: 인원 규칙 0~40명 전 구간, 평준화/전문화, 드래그 이동, 확정/불러오기, 날짜별 보관
- 브라우저 자동 조작(Chromium, PC 1200px와 휴대폰 390px): A~H의 ✅ 항목 확인
- 아이폰 환경 흉내(Chromium에 iPhone 사용자 에이전트, 터치 입력, 390×844 화면): J의 ✅ 항목 확인. 실제 Safari 공유 시트는 개발 환경에 없어서 "호출"까지만 확인함

### 알려진 제한
- 첫 접속 때 한글 폰트와 화면 엔진(약 15MB)을 내려받으므로 처음 한 번은 몇 초 걸립니다.
